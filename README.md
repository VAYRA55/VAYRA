# VAYRA Store — GitHub Pages

## Included
- Responsive VAYRA clothing storefront
- Product selection (colour + size)
- Working local cart with quantity controls
- Checkout form
- Cash on Delivery
- UPI payment flow with QR support
- WhatsApp order confirmation
- VAYRA logo asset
- GitHub Pages-ready static files

## Before launch
Open `config.js` and replace:
`upiId: "YOUR-UPI-ID@upi"`
with your real UPI ID.

Example:
`upiId: "wearvayra@upi"`

## GitHub Pages
Upload the files so `index.html` is in the repository root.
Then enable:
Settings → Pages → Deploy from branch → main → /(root)

## Product image
`assets/pluse-tee.svg` is a temporary product mockup. Replace it with your real product photo if you have one, keeping the filename or updating `config.js`.
